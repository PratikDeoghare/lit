Install and remove

One binary, one command: lit. It is a Go program that uses only the standard library and the brashtag parser, and the skill is inside it. There is nothing else to install; the skill's scripts are Python and need only python3, which an assistant usually has already. Nothing is written anywhere except the skill folder you ask for.

Install

go build -o lit ./cmd/lit

In the tangled source of this document. Put the binary on your path.

lit install-skill

The skill goes to ~/.claude/skills/brashtag-literate. For one project only, use lit install-skill --dest .claude/skills. Installing again upgrades it.

Remove

lit uninstall

Removes the skill folder, then asks before removing the binary. Use --yes to skip the question, or lit uninstall-skill to remove only the skill. A folder with the skill's name that lit did not create is never touched unless you pass --force. lit where shows what is installed and which parser is in use.
